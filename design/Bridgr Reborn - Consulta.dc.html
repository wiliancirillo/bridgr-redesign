Imediata: a trava é tomada antes de checar a sessão, então "ocupado" não gasta segundos. Nenhuma linha de rastro é escrita — a consulta não saiu.
Fantasma: o Fantasma precisa estar com a sessão aberta para consultar — ligue em Configurações → Fantasma

Esta é a recusa que nunca pode virar "Nenhuma linha." — vazio só existe quando foi provado.
Comentário: pintado como erro
SELECT cd_lote FROM Lote
-- só os de setembro
O portão recusa comentário, e a mensagem do Everest não diz isso — então a cor já diz.
Fora do ASCII: marcado no lugar
WHERE nm_paciente = 'JOÃO'
Acento quebra no caminho da área de transferência. O critério é "fora do ASCII", não uma lista.
As quatro dicas, agora também aqui — avisam, nunca barram
Comparar com NULL (= NULL, <> NULL) nunca é verdadeiro: as linhas somem sem erro nenhum. Use IS NULL ou IS NOT NULL.
BETWEEN com duas datas sem hora perde o último dia inteiro se a coluna for datetime. Prefira >= data e < dia seguinte.
O app já tinha estas dicas no diálogo do SQL dos Catálogos; a Consulta, onde as consultas são escritas à mão, não as mostrava.
