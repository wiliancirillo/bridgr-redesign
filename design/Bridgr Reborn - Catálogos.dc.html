5 · O SQL deste catálogo
a página e a contagem são uma pergunta só · o aviso vem antes de qualquer edição
O SQL deste catálogo
Médicos · É esta consulta que a coleta manda ao Everest, página por página.
editado
Editar aqui muda o que o catálogo traz. Um SELECT errado custa uma coleta inteira — e o filtro de classe é o que separa um espelho de 153 mil nomes de pacientes: ele não pode sair, e o app recusa se sair.
O que precisa continuar aí: {after} · as colunas id descricao apelido registro situacao fim
Os valores são os do ERP, não os da tela: SITUAÇÃO aparece como “ativo” aqui e é `A` no banco.
A consulta das páginas
1
SELECT TOP 500 c.cd_cadastro AS id, RTRIM(LTRIM(c.razao)) AS descricao, RTRIM(LTRIM(c.fantasia)) AS apelido, RTRIM(LTRIM(ISNULL(e.cd_crm, ''))) AS registro, RTRIM(LTRIM(c.situacao)) AS situacao, '.' AS fim FROM dbo.Cadastro c INNER JOIN dbo.CadastroClasse cc ON cc.cd_cadastro = c.cd_cadastro INNER JOIN dbo.Classe cl ON cl.cd_classe = cc.cd_classe LEFT JOIN dbo.cadastroEXT e ON e.cd_cadastro = c.cd_cadastro WHERE c.cd_cadastro > '{after}' AND cl.nome = "MEDICO" ORDER BY c.cd_cadastro
A contagem
1
SELECT COUNT(*) AS total FROM dbo.Cadastro c INNER JOIN dbo.CadastroClasse cc ON cc.cd_cadastro = c.cd_cadastro INNER JOIN dbo.Classe cl ON cl.cd_classe = cc.cd_classe WHERE cl.nome = 'MEDICO'
É ela que prova que a coleta chegou ao fim. Se você filtrar a consulta acima, filtre aqui também — senão a coleta é recusada por ter parado cedo.
Aspas duplas são identificador no SQL Server, não texto — "ativo" vira nome de coluna e a consulta é recusada. Use aspas simples.
Tire o ponto-e-vírgula do fim: a consulta de página é embrulhada para paginar, e ele cai no meio do embrulho.
O espelho em disco continua o da coleta anterior; o novo SQL vale a partir da próxima.

Estados da linha
